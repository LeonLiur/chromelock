# ChromeLock Installation Guide for Dia Browser

## Quick Start

Your ChromeLock extension is ready to use! Follow these simple steps:

### 1. Open Dia Browser Extensions Page

In Dia browser, navigate to:
```
dia://extensions
```
Or alternatively:
```
chrome://extensions
```

### 2. Enable Developer Mode

Look for the **Developer mode** toggle in the top-right corner of the extensions page and turn it ON.

### 3. Load the Extension

1. Click the **"Load unpacked"** button
2. Navigate to this folder: `/Users/leonliur/Coding-Projects/Side-Projects/chromelock`
3. Click **"Select"** or **"Open"**

### 4. Start Using ChromeLock

- Look for the ChromeLock icon 🔒 in your browser toolbar
- Click it to open the popup and manage blocked sites
- The extension comes pre-loaded with these sites:
  - youtube.com
  - linkedin.com
  - facebook.com
  - twitter.com
  - reddit.com
  - instagram.com

## How to Use

### Block a New Site

1. Click the ChromeLock icon in your toolbar
2. Type the website domain (e.g., `tiktok.com`)
3. Press Enter or click "Add Site"
4. The site is now blocked!

### Unblock a Site

1. Click the ChromeLock icon
2. Find the site in your blocked list
3. Click the **×** button next to it
4. The site is now unblocked!

## Testing

Try visiting any blocked site (e.g., `youtube.com`). You should see a beautiful blocked page with a motivational message instead of the actual site.

## Troubleshooting

**Extension not appearing:**
- Make sure Developer Mode is enabled
- Try reloading the extension from the extensions page

**Sites not blocking:**
- Check that the site is in your blocked list
- Try refreshing the page you want to block
- Verify you entered just the domain (e.g., `youtube.com`, not `https://youtube.com`)

**Need to temporarily disable:**
- Go to `dia://extensions`
- Toggle off ChromeLock
- Toggle back on when you want to re-enable blocking
